# SISTEMA DE GESTIÓN DE TICKETS CON ÁRBOLES DE DECISIÓN PARA CLASIFICAR URGENCIAS

Sistema avanzado de gestión de tickets que utiliza árboles de decisión para clasificación automática de urgencias y generación de soluciones personalizadas.

## Características principales 

-  Clasificación automática de tickets por nivel de urgencia
-  Modelo predictivo basado en árboles de decisión
-  Dashboard interactivo para seguimiento de tickets
-  Búsqueda inteligente de soluciones basadas en historial
-  Generación de reportes estadísticos

## Requisitos del sistema 

- Python 3.10 o superior
- pip 23.0 o superior
- Sistema operativo: Windows/Linux/macOS

## Instalación
- pip install -r requirements.txt
- winget upgrade --id Python.Python.3
